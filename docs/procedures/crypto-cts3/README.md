## Contract and normative sources

NIST SP800-38A Addendum (October2010), section4, defines CBC-CS3 with an unconditional swap of the final complete CBC ciphertext block and the preceding (possibly partial) block. RFC3962 section5 gives the same Kerberos variant and carries the final CBC ciphertext block (the next-to-last block in CS3 output) as the next IV. RFC3962 AppendixB supplies primary published AES vectors. We use byte lengths only, not partial bits. Source documents, hashes, exact-pin upstream code/license and actual tool/dependency inputs are bound in evidence.

The selected ccpad.h contract is strictly nbytes>block_size; this wins over RFC's additional single-block/padded-short behavior. The selected NFS gss_krb5_mech.c routes <=block through a separate path and sends only a tail in(block,2*block] to CTS3 after ordinary CBC prefix processing. It ignores the size_t result. We return nbytes on successful length-preserving processing and0 on rejected/error input, a local deterministic boundary consistent with the selected size_t callback and absent-provider wrapper's0. No private Apple error/return behavior is established. Future native integration must address the caller's ignored result; no provider or native success follows from this component.

Production functions are s24_cts3_encrypt/decrypt with the exact selected ccpad_cts3_crypt_fn_t types. They are generic over an initialized genuine CBC descriptor/context of the appropriate direction, bounded to the selected CCMODE_MAX_BLOCK_SIZE for fixed local scratch. They do not expand keys or infer a mode's direction from invented metadata. Real backend allocation sizes, initialization, mode immutability and buffer ownership remain caller responsibilities. CBC's const context contract is retained.

Admitted operations allow exact in-place or disjoint data, reject partial overlap and reject context/descriptor/IV/data overlaps before writing. Numeric extents and quotient-based tail arithmetic avoid overflow. Short inputs0..block and malformed/null pointers/descriptors are admission failures and preserve all buffers. The caller IV is copied locally and committed only after every CBC call succeeds. On an admitted mid-CBC error, the entire advertised output is cleared with the single accepted zeroizer and caller IV remains unchanged. In-place input is therefore cleared, not restored. No private failure-equivalence claim is made. Temporary plaintext, cipher blocks and IVs are cleared. Split equivalence is ordinary CBC over a complete prefix followed by CTS3 over the remaining >block tail; independently applying CTS3 to arbitrary chunks is not a streaming equivalence.
