# Guest shard reviews of 2026-11-10

`hash_review.py` is the exact read-only script used for the VM-014, VM-019, VM-042 and VM-043 reviews. The evidence files cite it as `scratchpad/hash_review.py`; this is the same file. Usage:

```sh
python3 -I docs/procedures/avf-object-shards/hash_review.py OUT.json WORKTREE WORKTREE/EVIDENCE.json
```

The script starts from one evidence file. It follows referenced JSON files up to two levels, but only inside the task's own worktree. It recomputes the SHA-256 of every named file there and checks that each `.o`/`.cpo` file has an ARM64 Mach-O MH_OBJECT header. Results:

| Task | Shard | Path/hash pairs | Objects | Result |
|---|---|---:|---:|---|
| VM-014 | libkern | 471 | 77 | all match |
| VM-019 | security | 151 | 23 | all match |
| VM-042 | osfmk-machine | 478 | 77 | all match |
| VM-043 | platform-support | 89 | 13 | all match |

These Firehose-profile guest objects were never linked into a kernel. The guest that VM-002 booted was built by the HakiOS route.
