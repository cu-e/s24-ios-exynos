# Доступ к устройству

Сначала нужен уже авторизованный ADB endpoint. Локальная инвентаризация не делает pairing, su, reboot, установку APK или запись в разделы. Разблокировка загрузчика и root — отдельные факты.

```sh
python3 tools/device_inventory.py --output devices/local-2026-11-05.json
```

При нескольких аппаратах передай `--device` явно. Серийник используется для выбора, но не сохраняется. Повторный запуск требует нового имени файла: старое наблюдение не перезаписывается.

Сохраняются выбранные getprop, uid shell, uname, размеры экрана. Не собираются IMEI, serial, MAC, аккаунты, список приложений, полный getprop и полные логи. `matches_reference_target` проверяет SM-S921B/e1s; false означает необходимость пересмотра применимости кода, не разрешение прошивать другой аппарат.

Беспроводной ADB можно настроить отдельно с владельцем. Он не переживает переход к ядру без собственного USB/Wi-Fi драйвера. Даже постоянный USB-кабель не создаёт управляющий канал в зависшем XNU.

Android-app этап — отдельная согласованная установка test APK с понятным удалением и ограничениями. Только после неё доступны GPU-003/GPU-005.
