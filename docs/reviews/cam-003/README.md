Every reserved interval must fit the declared abstract allocation, meet required capacity and bound used count. Subtraction precedes endpoint addition, so pairwise overlap tests use already-bounded ends (`frame.c:44-55`). Overlap includes unused padding and metadata. Completed images must report at least their full required size; extra used bytes still cannot exceed capacity. Unused plane descriptors must be zero. Queue semantics match the declared serialized, zero-initialized caller contract. Submit copies the descriptor and reserves an epoch/ticket with zero used counts (`frame.c:82-96`). Complete copies exactly three counts to local storage and validates a local frame before READY; producer errors, malformed counts, invalid payloads or timeout retire the reservation (`frame.c:98-119`). Take copies descriptor/layout values and holds the reservation, not an immutable image-byte snapshot. Mutating caller input, the completion-count array or the returned descriptor after its call does not modify queue copies. This is not concurrent-DMA snapshot or pixel copying; accessible buffers, independent state/output storage and serialization are preconditions.

Stop keeps INFLIGHT/READY reservations RETIRED and keeps a consumer HELD frame held (`frame.c:121-138`). A held release is distinct from a trusted quiescence acknowledgement for retirement. Neither an error nor a logical Stop permits immediate reuse. Fresh increasing epochs prevent old same-ticket completions from matching within this queue lifetime; restart/peer identity binding and actual DMA quiescence remain external. Ticket/epoch counters do not wrap. Clock arithmetic is checked, deadline equality expires, and polling must really be scheduled by an integrator. No timer, lock, hardware stop or recovery mechanism is supplied by these state flags.
