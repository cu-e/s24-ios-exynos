**Bounded conclusion: no actionable P0/P1/P2 finding in this host admission boundary.** Two adversarial counterexamples reproduce limitations already documented by the candidate: an unpadded 1088-byte UCD pool stride loses address bits, and software epochs cannot disambiguate old same-address/same-tag wire completions without backend drain. The READ-only allowlist rejects every non-READ(10) opcode, non-device-to-host direction, unsupported CDB flag/group/control byte and zero count before admitting a request (`host.c:41-65`). Ten CDB bytes are required before any CDB field read. Capacity and selected-extent tests subtract before adding; the uint32 LBA boundary is explicit. Count is at most 65535 and block size 512/4096, so their uint64 product is bounded before the 1 MiB policy check. DMA policy checks alignment, nonzero bases, full-region sizes, addition overflow and overlap before request construction (`host.c:10-24`). These are caller-qualified numeric regions, not evidence of mappings, ownership or permission to read a partition.

The genuine Samsung `utp_transfer_req_desc`, `cq_entry`, `ufshcd_sg_entry`, `utp_upiu_header` and `utp_cmd_rsp` declarations establish 32/32/16/12/40-byte sizes and field positions. Candidate UTRD direction/command/interrupt fields agree with the original enums. Response/PRDT length precedes DWORD offset in each UTRD/CQE DWORD. The candidate's 512-byte command/response slots, response length/offset 128 DWORDs and PRDT offset 256 DWORDs agree. PRDT entries preserve 64-bit addresses and bytes-minus-one size, with at most four 256 KiB chunks (`host.c:67-85`). Bounds place the final PRDT byte inside the 1088-byte owned UCD. UPIU multibyte fields use big endian, descriptor multibyte fields little endian.

Completion uses exact 32-byte CQE extent and 52..512-byte response extent before parsing (`host.c:114-118`). Genuine Samsung `ufs-mcq.c:258-274` states that CQE lacks a task tag: address bits 63:7 identify UCD, bits 4:0 contain SQ ID, and 6:5 are reserved. The candidate checks address/SQ and reserved bits independently, then UPIU LUN/tag and expected descriptor dimensions (`host.c:119-126`). It rejects OCS/status, response type/flags, residual, sense length and unsupported header/data-segment fields before COMPLETE (`host.c:127-135`). Reserved response-body bytes and bytes beyond zero sense length are not treated as extra data. This strict profile may reject valid protocol variants; it does not claim generic UFS/SCSI support.

The lease model is conservative under its documented serialized caller contract. Reservation precedes real backend publication; logical cancellation is then forbidden even if publication fails (`host.c:89-98`,144-150). Stale/malformed completions retain ownership; matching status errors and deadline expiry quarantine. The boundary has no recovery/reset API or automatic retry. A syntactically valid completion calls the time checker before wire matching, so a stale arrival may advance the caller-supplied monotonic observation or trigger the real deadline; it cannot release the lease. Invalid-length completions leave timeout observation to an explicit later poll. Successful completion still blocks preparation until backend reclaim (`host.c:137-142`), whose precondition is actual CPU DMA ownership plus completion consumption. A boolean state cannot establish those physical facts. Generation/tag never wraps within an epoch and even canceled preparations consume a tag.

The adversarial checks also demonstrate the two documented native gates:

- Actual Samsung tag recovery with base 0x100000, stride 1088 and address `base+1088+31` reports slot 0 rather than slot 1: masking bits6:0 loses the unaligned 64-byte part. With stride 1152, slot 1 is recovered. The donor's single 1088-byte UCD is suitable only as an isolated aligned allocation; it is not a 128-aligned pool stride. The candidate compares one fixed UCD address and never derives a pool tag by 1088-byte division. A future pooled backend needs separately qualified padded allocation rules.
- Two independent logical states deliberately reused the same DMA policy/address/tag while the earlier lease was still live, violating exclusive ownership/drain requirements. An old software token is rejected by the new epoch, but identical CQE/response bytes supplied with the current token are accepted. The wire has no epoch. This is the documented reason fresh/retired initialization requires physical quiescence, queue drain and DMA return before reuse. This harness deliberately violates that precondition to demonstrate its necessity; it does not suggest such reuse is supported.
