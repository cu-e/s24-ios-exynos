## Acceptance

- A window harness run on the real device-tree facts (devices/e1s-fdt/2026-11-10/runtime.facts.json) returns base 0x8cb800000 and size 4908 MiB, a harness case with a gap below 256 MiB is rejected, and an old-rule case returns the NAT-068 window 0x9de400000 / 512 MiB (docs/procedures/nat-073/budget.py is a cross-check, not the oracle).
- The emitted loader code, checked by disassembly and a unicorn model: clears at most 64 MiB plus BSS; cleans the whole window by VA; polls a deadline cap constant and pets the watchdog every 30 s only before the cap; never pets after it; the NAT-044 reset path is unchanged and still the exit at the cap. NAT-020&#x27;s forbidden-symbol rule is amended for s5e_wdt_pet in this image only and the amendment is listed. Mutants on the new hunks (cap, pet period, comparison direction, clear size, alignment) are killed or survivors listed.
- ADT RAMDisk size is a multiple of 16 KiB (2,475,712,512 + 8192 B accounts for the 8192 remainder); the image builder pads and rejects other sizes; the payload header and boot_args memSize equal the window. A decision draft for NAT-075 names the pass rule; no native run in this task.
