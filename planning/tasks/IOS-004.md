## Acceptance

- tools/ios/udif.py parses the 512-byte koly trailer, the XML property list and every blkx/mish table with bounds checks (sector counts, data offsets and lengths inside the file, no allocation of the size a header claims before it is checked); exposes info(), read(offset, length) across chunk boundaries, and a streaming iterator with a fixed memory bound; LZFSE chunks use tools/ios/lzfse_py.py. Every damaged input ends in UdifError, never IndexError/struct.error/unbounded loop. No upstream code is compiled or executed (y2sios dmg.py is a reference for the format description only).
- tests/test_udif.py builds UDIF images in the test (all supported chunk types, multi-partition, chunk boundary reads, zero-length, truncated and corrupted trailers/tables) from the public format description, not from the reader&#x27;s own helper; a mutation pass over the reader (as for IOS-002) kills every chosen mutant or lists survivors.
- Smoke check on the local rootfs image artifacts/apple-inputs/.../096-04088-077.dmg: info lists partitions, chunk-type histogram and decompressed size; the decompressed bytes at the start of the APFS partition carry the container magic NXSB at offset 32; time and memory per MiB decompressed are recorded. Only counts, hashes and sizes are committed; no Apple data is copied into Git.
