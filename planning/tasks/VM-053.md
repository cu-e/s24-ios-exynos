## Acceptance

- s24vmm reserves an SCFB region below the FDT, passes scfb.addr/size/w/h to avfboot and streams published frames (frame_seq, POLL, DAMAGE, seqlock with drawing/host_reading as in scion-avf patch 1200/1204) to a localhost client.
- s24vmm exposes a virtio-mmio v2 virtio-input multitouch device at 0x0a000000 (SPI 16, INTID 48) with name and ABS_INFO for ABS_X/Y and ABS_MT_POSITION_X/Y, fills eventq buffers with MT-B events and raises/lowers its level interrupt through KVM_IRQ_LINE.
- Host tests cover the SCFB reader, virtio-mmio registers, split virtqueue handling, the input event encoding and the frame protocol; a project viewer APK builds reproducibly and decodes the frame protocol in a host test.
- No claim of device behaviour: the device run is a separate task.
