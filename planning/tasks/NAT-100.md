# NAT-100 — Observability small root on the host: a launchd-independent heartbeat. src/hb.c is a freestanding static arm64 Mach-O (raw Darwin system calls, built with NAT-077&#x27;s clang + lld + mkstatic pipeline) that writes a marker line and runs Apple&#x27;s /bin/ps (odd rounds `ps -A`, even rounds `ps -Ao pid,ppid,stat,comm`) with its output on /dev/console every 10 s, kills a ps that hangs and never touches anything else; the small root is NAT-096&#x27;s Stage A small root plus bin/hb and one added rc line `/redwood/bin/hb &amp;` before `exec /sbin/launchd.darwin`. Reason: NAT-098 lost both launchd&#x27;s console lines and the com.nat085.ps job&#x27;s lists after Apple&#x27;s logd ran (hypothesis H-logd, untested); hb separates a lost console path from lost launchd routing and, when it works, lists the processes that exist (blocker B7). A host model of the control flow (libc shims) is tested; the raw Darwin system-call layer is not testable on the host. No image, no driver, no decision and no run here

## Acceptance

- docs/procedures/nat-100/build_hb.py builds src/hb.c into a static arm64 Mach-O (only __PAGEZERO/__TEXT/__LINKEDIT, LC_UNIXTHREAD, no dylib, no LC_MAIN) with NAT-077&#x27;s pipeline and audits its structure; hb.json records the source, tool and result hashes. The target build is byte-identical with and without the host-model code in the source.
- docs/procedures/nat-100/build_hb_root.py builds artifacts/nat-100/pid1-hb/root.apfs from NAT-096&#x27;s root tree (pinned by root.apfs SHA-256 and etc/rc SHA-256) and refuses any other base, a non-static hb, an rc that does not end with the exec line and an existing output directory; the tree differs from the base in exactly bin/hb (added) and etc/rc (changed: one comment block and the line `/redwood/bin/hb &amp;` directly before the exec line); the image is read back by the kernel&#x27;s apfs_lib (every file and mode) and by verify.py content.
- Host tests: the C control flow is run through a libc model (normal rounds and their output format, a hanging ps killed after the timeout with the loop continuing, a missing ps, a missing console, a failing fork) and the builders&#x27; refusals and tree differences are checked with the real artifacts (skipped when absent). A mutation pass over hb.c and the builders is run (RAM-capped) or its absence is stated. Nothing here ran on a phone and the raw Darwin system-call layer (numbers, the x1 child flag, the carry convention) is not covered by any host test; the evidence says so.
