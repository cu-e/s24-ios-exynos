## Acceptance

- From the pinned vendor kernel (exynos-reboot, sec_reboot, PMU INFORM/SYSIP_DAT definitions and the Samsung reboot-reason constants) the register, offset and value the Android kernel writes before a warm reset for reboot-to-download and reboot-to-system are listed with file and line, and compared with what the existing loader already writes (PMU INFORM 0xbc, one-shot recovery-reason clearing, watchdog 83 s).
- A host-testable patch design for the loader (and its decision text) makes the end of a bounded run reset into Download Mode so NAT-013 can restore stock unattended; the unknown of whether S-Boot honours the reason while its persistent REBOOT_MODE=4 parameter is set is stated and gets its own measurement in the native run.
- No S-Boot disassembly or static review is used (classifier stop recorded in NAT-009); only the open vendor kernel source and the already measured behaviour of runs 001-009.
