## Acceptance

- The DECON0 trigger registers (TRIG_CON, SHD_REG_UP_REQ, GLOBAL_CON, FRAME_COUNT) and the vendor driver&#x27;s command-mode frame sequence are recorded with file, line and the pinned BSP SHA, plus the DT trig_mode/op_mode facts, in a source-review note.
- A canary-trig image is built reproducibly; the plain and fault canaries stay byte-identical to the ones already built. The kick performs no MMIO before the first framebuffer marker, writes only TRIG_CON and SHD_REG_UP_REQ, and writes nothing when DECON is off, in video mode, with the MMU on, or after a faulted kick; host tests assert these properties and the decoder reads the register report back.
- Nothing is flashed or run on the phone: the MMIO writes are outside decision 0009, so an image-specific decision request with the exact SHA-256, the writes, risks and recovery is prepared for the owner.
