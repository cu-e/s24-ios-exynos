## Acceptance

- An ordered plan, each step with its source file and line at the pinned commit, of what the vendor driver writes between a cold HSI0 and a DWC3 device that runs: power domain (PMU offsets 0x61c/0x620), CMU_HSI0 clocks, SYSREG_HSI0 USB configuration, eUSB2 PHY init, repeater I2C writes (TUSB2E11 0x3e / PTN3222 0x4f), USBDP combo PHY (version 0x801, RAM mode) including whether high-speed device mode needs its pipe clock or RAM code, DWC3 soft reset, GCTL/GUSB2PHYCFG/GUSB3PIPECTL/DCFG, event buffer, endpoint 0 commands, run/stop.
- The minimal subset for a high-speed-only EP0 device is separated from the full vendor sequence with the reason for each omitted step; every step the loader cannot know (regulators, PMIC, GPIO, repeater selection) is listed as an unknown with the measurement that resolves it (NAT-039 on Android, NAT-043 in the loader).
- Register addresses are computed from the pinned DT and driver sources and cross-checked against the USB-001 profile; nothing is claimed about the live firmware.
