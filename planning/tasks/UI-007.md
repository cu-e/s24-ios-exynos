## Acceptance

- The s5e9945 (cal_rt) DECON window enable/channel-map and DPP/DMA base address, pitch/stride, pixel format and source size register offsets and bit fields are cited with file:line from the pinned s24-linux (and s24-bsp-reference) revisions, and how Samsung&#x27;s driver consumes s3cfb.bootloaderfb is cited.
- DPP/DMA MMIO bases used by the reader come from the NAT-005 runtime FDT and are published only as sanitized facts.
- A freestanding C module (stdint only, no writes, volatile 32-bit reads through caller-supplied bases) returns {enabled, base, stride, format, width, height} for the boot window and validates it against an expected base/size; it compiles for aarch64 freestanding with the loader&#x27;s flags.
- Host tests with clang ASan/UBSan run on a simulated register file whose values are encoded from the cited register definitions, not from the implementation, and include rejection cases.
- The report separates facts cited from source, facts measured on this phone and facts that remain unverified until a native run; no device I/O is performed.

2. Extract DPU/DPP node bases from the local runtime FDT with sanitized output
3. Implement the read-only reader and the independent simulated-register host tests
