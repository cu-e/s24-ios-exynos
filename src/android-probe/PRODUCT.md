# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Users

The S24 owner and researchers need repeatable, short Vulkan measurements while retaining Android. This is an experimental measurement utility, not an iOS launcher.

## Product purpose

Run an owned offscreen GPU fixture, show its actual result, stop further work, and export a sanitized report. Success is a correct measurable result and bounded process behavior, not a fabricated screen or benchmark.

## Capabilities and constraints

The approved plan specifies Start/Stop, short runs, load limits, private result storage and clean export. No root, device administration, accessibility service, network permission, system library replacement or partition operation. Primary-phone installation remains separately gated. Android kernel GPU failure cannot be contained by an app guarantee.

## Operating context

English product and report text. Host builds and emulator checks precede any primary-device installation. Native Android controls are sufficient for this narrowly specified utility; there is no brand or marketing surface to establish.

## Evidence on hand

The dated S24 inventory identifies Xclipse 940 and stock Vulkan. It is inventory, not a successful run of this app. Host and emulator results must identify their environment.
